<h3 align="center">Always shipping something.</h3>

I spend most of my time building backend systems in Go and Python, usually with FastAPI on the Python side and a lot of PostgreSQL underneath. Lately I've been drawn to the messy parts of distributed microservices — the failure modes, the consistency questions, the moment you realize your clean API design has to survive a partial outage. Most of my thinking happens between Redis, Docker, and whatever query plan is surprising me that week.
